# 宣传片源码

45 秒，1920 × 1080，60 fps，H.264 / AAC。中文字幕已绘入画面，无配音；背景音乐也由代码原创合成。

`render.cjs` 包含画面、动效时间轴、中文字幕、模拟界面、程序化山景和配乐。画面展示插件的实际功能逻辑，界面为简化演示，未使用私人对话、登录信息或第三方视频。未采用旧录屏或下载素材。

## 渲染

需要 Node.js 24+、FFmpeg 和中文字体。

```sh
cd promo
npm ci
npm run preview
npm run render
```

- `FFMPEG`：FFmpeg 可执行文件路径，默认从 PATH 查找。
- `PROMO_OUT`：输出目录，默认 `promo/rendered/`。
- `PROMO_FONT`：可选中文字体文件路径。默认使用系统微软雅黑或 Noto Sans CJK SC。

输出包括 MP4、封面、8 张关键帧和原创 WAV 配乐。`--preview` 只生成关键帧及封面。字体文件不随源码分发。

## 分镜

| 时间 | 内容 |
|---|---|
| 00–04 | Agent 在忙，等待可以轻松一点 |
| 04–08 | 产品图标与名称 |
| 08–17 | Agent 开工，抖音侧栏展开，视频播放 |
| 17–24 | 审核提醒，视频冻结，点击批准 |
| 24–31 | Agent 继续，视频恢复 |
| 31–36 | 任务完成，播放暂停 |
| 36–40.5 | 原生侧栏、会话联动、共享登录 |
| 40.5–45 | 开源地址与上游署名 |
